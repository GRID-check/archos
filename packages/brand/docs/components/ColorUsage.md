# Farbeinsatz

Übersicht, welche Farbe auf der Website wofür steht: Weiß trägt die Seite, Schwarz den Inhalt und die Haupthandlung, ein helles Grau hebt bis zu zwei Abschnitte ab, eine dunkle Karte und der Footer setzen den Kontrast.

Keine Komponente, sondern eine Referenz. Die Hex-Werte liest die Übersicht live aus den Tokens. Die roten Ziffern sind nur Beschriftung dieser Übersicht und gehören nicht zum Auftritt.
