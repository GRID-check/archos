# PostCard

Beitrag im Blog-Raster: Bild 3:2, Titel, Anriss, Datum – die ganze Karte ist der Link.

**Props:** `title` (`heading-3`, höchstens 356px), `text` (`body`/`ink-muted`, ein bis zwei Sätze), `date` (`small`/`ink-muted`), `href`, `media` (Bild 3:2).

- Raster `ui-posts`: drei Spalten, `space-8` Spaltenabstand, 80px Zeilenabstand; zwei Spalten unter 1024px, eine unter 768px.
- Darüber der Filter `ui-filter` aus `ui-nav-link` (Alle · Produktfeatures · Praxiserfahrungen · Technologie, aktiver unterstrichen), darunter mittig „Weitere Beiträge“ als Sekundär-Button `lg`.
- Hover unterstreicht den Titel. Keine Kategorie-Labels auf der Karte, keine große Vorschau eines Hauptbeitrags.
