# Timeline

Ausbaustufen als feine, geteilte Linie: der heutige Abschnitt in `ink`, die späteren in `ink-faint`; darunter Stufe und Text.

**Props:** `steps` – `[{ when, text }]` (Heute · Als Nächstes · Langfristig); `current` – Index der heutigen Stufe (Standard 0).

- Linie `stroke-strong` (2px), Lücke `space-1` zwischen den Abschnitten, eckig.
- Stufe `heading-3` (heute `ink`, sonst `ink-muted`), Text `body` in `ink-muted`.
- Keine Bilder, keine Punkte oder Pillen. Unter 1024px untereinander.
